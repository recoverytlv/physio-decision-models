# Tendinopathy Non-Response Framework

> A clinical branch of the [MSK Physiotherapy Non-Response Decision
> Framework](./NON_RESPONSE_FRAMEWORK.md). Proposed by **Alejandro Zubrisky, BPT**
> (Recovery TLV · ORCID 0009-0003-1069-937X · concept DOI 10.5281/zenodo.20683788).
> Supports decision-making; not a guideline, does not replace clinical judgement.

**Question:** *How do we distinguish expected slow tendon adaptation from true
non-response to rehabilitation — and decide whether to continue, modify, refer or
stop?*

## Central claim (citable)

> In tendinopathy, non-response should be judged by the **absence of meaningful
> change in pain, function and load capacity after an adequate, progressive and
> adherent rehabilitation trial — not by pain persistence alone.**

Tendon loading is first-line care for load-induced tendinopathy; improvement is
often **slow**, and tolerable pain during loading is not equivalent to failure
(Cook & Purdam 2009; Alfredson 1998; Beyer 2015; Malliaras 2013; Chimenti 2024;
Desmeules 2025).

## Domains of (non-)response in tendinopathy

| Domain | Example signals |
|---|---|
| Pain | NPRS during loading; 24-h post-load response |
| Function | VISA-A (Achilles), VISA-P (patellar), SPADI/DASH (RC), region PROMs |
| Load capacity | Heel raises, hop tests, strength, tempo, volume tolerated |
| Irritability | Symptom response during and after exercise |
| Adherence | Real completion of progressive loading |
| Progression | Tolerated increase in intensity/volume |
| Participation | Running, jumping, gym, work, sport |

## Adequate-dose gate (before labelling non-response)

Was loading progressive, of sufficient intensity/volume, sustained long enough,
and actually adhered to? If not → **inadequate treatment**, not non-response.

## Decision table (the citable core)

| Finding | Interpretation | Decision |
|---|---|---|
| Pain during loading tolerable, returns to baseline within 24 h | Acceptable tendon response | **Continue / progress** |
| Pain persists but function / load capacity improving | Partial positive response | **Continue with monitoring** |
| Pain increases week-to-week and function declines | Excessive irritability / overload | **Modify load** |
| No objective improvement despite adequate loading + adherence | Possible true non-response | **Reassess diagnosis & plan (modify); stop if still none** |
| Low / inconsistent adherence | Invalid treatment trial | **Address adherence before labelling non-response** |
| Sudden sharp pain, pop, bruising, loss of force | Possible tendon rupture | **Urgent referral** |
| Persistent severe pain, systemic symptoms, atypical presentation | Non-mechanical / complex | **Medical referral** |
| Functional goals reached with residual mild symptoms | Successful functional response | **Discharge / self-management** |

## Algorithm

```
Baseline (pain on loading, function PROM, load-capacity test)
  → adequate, progressive, adherent loading trial
    → re-measure pain (during/24 h) + function + load capacity
      A. tolerable load pain + improving capacity → CONTINUE / progress
      B. pain same, function/capacity improving   → CONTINUE (monitor)
      C. worsening week-to-week                   → MODIFY load
      D. no change + adequate dose/adherence      → reassess dx (MODIFY) → STOP if none
      E. inadequate adherence/dose                → fix trial, do not label non-response
      F. red flags / suspected rupture            → REFER (urgent if rupture)
```

## Application by tendon (priority order)

| Tendon | Context | Key PROM / test |
|---|---|---|
| **Achilles** (Nivel 1) | Runners, load/progression model | VISA-A; heel-raise capacity |
| **Patellar** (Nivel 1) | Jumping sports, gym, basketball | VISA-P; decline squat |
| **Rotator cuff** (Nivel 1) | High clinical demand, adults | SPADI/DASH; loaded strength |
| **Lateral epicondylalgia** (Nivel 1) | Tennis/CrossFit/office | grip strength; PRTEE |
| Gluteal / proximal hamstring (Nivel 2) | Hip, runners | LEFS; load tolerance |
| Tibial posterior, De Quervain (Nivel 2) | Foot/ankle, hand/wrist | region PROM |

## Research gaps

No uniform operational definition of tendinopathy non-response; few decision
rules separating slow adaptation from failure; sparse evidence on the early
decision window; adherence rarely documented before non-responder classification.
