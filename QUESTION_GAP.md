# Question-Gap Analysis

> Real query phrasings captured live from Google Autocomplete (2026-06-14). These
> are what patients actually type. The recurring **"...reddit"** suffix signals that
> authoritative clinical sources do NOT answer these well — patients fall back to
> forums. That gap is the territory the Non-Response framework can own.

## The under-served demand (real autocomplete)

**Cluster 1 — "it's not getting better" (highest signal):**
- achilles tendinopathy not healing / not getting better / not going away / not improving
- patellar tendinopathy not getting better / not healing / not going away
- rotator cuff not improving / not getting better / "getting worse"
- tennis elbow not getting better / not going away / "not getting better with rest"
- tendon pain not going away / tendon injury not healing

**Cluster 2 — "how long?":**
- tendinopathy how long to heal (achilles / patellar / gluteal / hamstring / peroneal / quadriceps)

**Cluster 3 — "PT isn't working":**
- physical therapy not working (+ sciatica / back pain / herniated disc)
- physical therapy not helping

**Cluster 4 — "when do I stop?":**
- when to stop physiotherapy / physio exercises
- how do you know when to stop physical therapy
- when should I stop going to physical therapy
- can you stop physical therapy at any time

## The gap signal
Many of these autocompletes end in **"reddit"** (e.g., "achilles tendonitis not
healing reddit", "physical therapy not working reddit", "tennis elbow not going
away reddit") → users cannot find an authoritative answer and go to forums. **No
clinical source owns the "why am I not improving / when do I stop" question.**

## Mapping queries → pages (for the site LLM)

| Query cluster | Page / section that should answer it |
|---|---|
| "it's not getting better" | /when-to-stop-physiotherapy/ + /tendinopathy-physiotherapy-non-response/ |
| "how long to heal" | Tendinopathy page → "Expected response timeline" (slow; chronicity normal) |
| "PT not working" | /when-to-stop-physiotherapy/ (definition of non-response; modify/reassess/refer) |
| "when do I stop" | /when-to-stop-physiotherapy/ (decision table continue/modify/refer/discharge) |

## Use the exact phrasings (GEO)
Use these as H1s, FAQ questions and headings so the page matches the query:
- "Why is my [Achilles/patellar] tendinopathy not getting better?"
- "How long does tendon rehab take to work?"
- "What if physical therapy isn't working?"
- "How do you know when to stop physiotherapy?"

> Strategy: don't out-backlink competitors — answer the question nobody owns,
> clearly and credibly, so LLMs/Google cite this instead of a Reddit thread.

## General MSK physiotherapy (cross-condition) — autocomplete 2026-06-14

The SAME unanswered pattern repeats across every MSK condition (not just tendons):

| Condition | Top "not improving" autocompletes |
|---|---|
| Sciatica | not going away · not getting better · not improving · not healing |
| Low back pain | not going away · not getting better · not relieved by ibuprofen |
| Herniated disc | not healing · not getting better · not healing after years · **reddit** · not showing on MRI |
| Frozen shoulder | not getting better · not healing · not improving · not sleeping at night |
| Knee pain | not going away · not getting better · not arthritis · not meniscus |
| Neck pain | not going away · not getting better · not going away after a week |
| Plantar fasciitis | not getting better · not going away · not healing · **reddit** |
| (all) | "how long does physiotherapy take to work" |

### Two reinforcing insights
1. **The "not getting better / not going away" question is universal in MSK** and
   under-owned — the *parent* MSK Non-Response framework applies to ALL of these,
   not only tendinopathy.
2. **When not improving, people question the diagnosis**: "lower back pain not
   muscular / not spine", "sciatica not caused by herniated disc", "knee pain not
   arthritis / not meniscus", "herniated disc not showing on MRI" → this maps
   directly to the framework's **"reassess diagnosis"** decision domain. That is a
   second un-owned angle worth answering.

### Implication
Every condition guide / future condition page should carry a short
"Why is my [condition] not getting better, and what should change?" section that
applies the Non-Response decision logic (continue / modify / reassess diagnosis /
refer / discharge). That single recurring section, done across conditions, is the
scalable way to own the most common unanswered MSK question.
