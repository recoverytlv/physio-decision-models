# Hebrew Blog Blocklist — Anti-Cannibalization Map

> **Purpose:** prevent new blog posts from competing with existing pages on
> recoverytlv.co.il. Mapped from the 150-question bank against ~95 condition
> hubs (`/conditions/`) and 28 existing blogs (`/blog/`). Updated 2026-06-14.

## Collision types

| Type | Meaning | Action |
|---|---|---|
| **HARD** | An existing hub or blog already covers this angle | Do NOT write a separate post |
| **PARTIAL** | Existing page touches the topic but a very different angle may survive | Confirm by reading the existing page before writing |
| **CLEAN** | Hub exists (for linking upward) but no blog covers the decision angle | Safe to write |

## Pre-publish checklist

Before publishing ANY Hebrew blog post, the writing LLM must answer:

| Question | If YES → |
|---|---|
| Could this H1 be the H1 of a condition page? | Change the angle |
| Does the post explain "everything about the condition"? | Cut — keep only the decision |
| Does the CTA compete with the service page? | Link to the hub instead |
| Is the primary keyword the same as the hub? | Switch to long-tail decision phrasing |
| Is this just a small FAQ? | Add as FAQ to the hub, not a separate post |
| Does the post add a new decision the hub doesn't cover? | Publish |

## Integrity note

This map is based on title/cluster-level analysis of the ~95 hubs and 28 blogs,
not word-by-word reading of all 28 blog entries. PARTIAL collisions should be
confirmed by reading the existing blog before writing.
